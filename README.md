# Prime Edu

Prime Edu v87 개발 공유본입니다. 최신 웹 UI, 학습 도구, AI API 서버 코드, 테스트, 모바일 앱 소스를 포함합니다. 프로그램 및 제공된 Apple 폰트 파일은 원본 그대로입니다.

## 로컬 화면 실행

Node.js를 설치한 뒤 저장소 폴더에서 실행하세요.

```sh
npm install
npx --yes serve . -l 5194
```

브라우저에서 `http://localhost:5194`를 여세요. 정적 서버에서는 화면을 확인할 수 있지만 `/api/*` 서버 기능은 별도 실행 환경이 필요합니다. Node.js 24와 자신의 환경 설정을 사용하는 Vercel 개발 환경에서는 `npx vercel dev`를 사용할 수 있습니다.

## 연결 설정

- Firebase 웹 설정은 클라이언트 공개 설정입니다. 관리자 권한이나 관리자 비밀키가 아닙니다. 독립적으로 개발할 때는 `js/firebase-config.example.js`를 참고해 자신의 Firebase 프로젝트를 사용하세요.
- AI API 키, Firebase 관리자 서비스 계정, Vercel 로그인/프로젝트 연결 파일 및 `.env*`는 포함하지 않습니다. 서버 기능에는 자신의 설정이 필요합니다.
- 이 저장소에는 실제 운영 사이트의 배포 권한이 없습니다. 공개 소스를 복제하는 것과 운영 사이트에 배포하는 권한은 별개입니다.
- 테스트용 로컬 예시는 `scripts/`에 있습니다. 예시 AI 응답은 실제 운영 AI 답변이 아닙니다.

## 공유 범위

원본 커밋 `74aaeb4`의 최신 파일 스냅샷입니다. 비밀 설정이 섞일 수 있는 과거 Git 이력, 개인 작업 폴더, 로컬 캐시 및 실제 관리자 연락처가 들어간 두 운영 보조 파일은 공개본에서 제외했습니다. 원본 작업 폴더와 운영 배포는 변경하지 않았습니다.

별도의 오픈소스 라이선스를 부여하지 않았습니다. 포함된 외부 폰트/라이브러리는 각각의 라이선스를 따릅니다. 제공된 Apple 폰트의 재배포 권한은 소유자가 확인했다고 안내했습니다.
